## 二、还没拿到的三块（以及结论）

### 1. PyCharm 的 Python Live Templates —— 已找到源，待并入

**不需要下载 900 MB 安装包。** 官方开源仓库里有：

```
https://raw.githubusercontent.com/JetBrains/intellij-community/master/python/python-code-insight/resources/liveTemplates/Python.xml
```

- 文件仅 **8857 B**，含 **15 条** 官方模板
- 已验证存在的缩写：`main`（if __name__ == '__main__'）、`iter`、`itere`、`compl`、`compli`、`super` 等
- 该目录下只有这一个 Python.xml；Django / Flask 等模块的模板还需再排查（仓库树被截断，`git/trees?recursive=1` 查不全，用 GitHub code search API 才能准确定位）
- 并入方式：按 `<template name/value/description>` 转成 `pycharm.json` 的 `pyc.tpl.*` 条目，`group` 写「代码模板·Python」，`code` 填展开文本（把 `$VAR$` 这类占位符原样保留）

### 2. Android Studio 的 Android 专属 Live Templates —— 缺源

- 这部分在闭源插件里，`JetBrains/intellij-community` 官方仓库没有
- 唯一途径是 Android Studio 安装包（约 1.2 GB），从中解包 `plugins/android/lib/*.jar` 里的 `liveTemplates/*.xml`
- 现状：已有 `as.tpl.java.*` / `as.tpl.kotlin.*` 共 58 条（复制自 IDEA），够用但与 Android 模板不同

### 3. Sublime 的 snippets —— 缺源

- 官方格式是独立的 `.sublime-snippet` 文件，散在 `sublimehq/Packages` 仓库各语言目录里
- 体量很小（仓库压缩包几 MB），不需要安装包；要按语言目录批量抓 `<content>` + `<tabTrigger>`

## 四、复现流程

脚本都在 `importers\_src\`，按顺序：

1. `fetch_cards.py` —— 下载官方键位卡 PDF / 官方网页到本目录
2. `parse_cards3.py` —— 解析成 `webstorm_entries.json` / `pycharm_entries.json` / `android_entries.json`
3. `merge_packs.py` —— 写进 `packs\*.json`（WebStorm 键位在前模板在后；PyCharm 整包替换；Android 键位 + 复制 IDEA 的 Java/Kotlin 模板），并做 `aliases`/`keys` 数组化兜底
4. `postfix.py` —— 同条目内 keys 去重、补键位卡上被换行挤掉的条目
5. `validate.py` —— 检查重复 id / 类型异常 / 空键

`importers\_merge_jetbrains_templates.ps1` 是另一条路：直接从本机 IDEA 安装目录的 jar 抽模板，可重复执行，同组同缩写自动跳过。

## 五、写盘注意

- 一律 UTF-8 无 BOM
- **`aliases` / `keys` 必须是数组**：PowerShell 的 `ConvertTo-Json` 会把单元素数组压成字符串，曾导致页面 `aliases.map()` 抛异常、界面卡在「读取配置中」
- 写完必须回读检查这两个字段的类型
